# Running Arena v0.6 — UI / 기록 / 프로필 통합 시제품

## 시작하기
1. ZIP을 압축 해제합니다.
2. 서버 컴퓨터에서 `server` 폴더를 VS Code 터미널로 엽니다.
3. 처음 실행 시 `npm install`, 이후 Windows CMD에서 `set PORT=3000` 다음 `npm start`를 실행합니다.
4. `app/index.html`을 VS Code Live Server로 실행합니다.
5. 서버 설정에 `ws://서버컴퓨터의IPv4주소:3000`을 입력하고 **주소 저장** 후 **연결 테스트**를 누릅니다. 같은 컴퓨터면 `ws://127.0.0.1:3000`도 됩니다.
6. 옆 컴퓨터는 같은 서버 주소를 입력하고 다른 계정으로 로그인합니다.

**기존 `server/data/users.json`을 삭제하거나 덮어쓰지 마세요.** 기존 계정 데이터가 보관되어 있습니다. 새 전적은 `server/data/history.json`에 저장됩니다. 두 파일은 개인정보를 포함하므로 외부에 공개하지 마세요.

## 사용자 이미지 넣기
`app` 폴더에 다음 이름으로 이미지를 넣으면 자동 반영됩니다.
- `mainbackground.jpg`: 첫 로그인 배경
- `home.jpg`: 메인 로비 상단 배경
- `mypage.jpg`: 향후 마이페이지 꾸미기용 이미지 (현재는 배경 미적용)
- `record.jpg`: 향후 전적 꾸미기용 이미지 (현재는 배경 미적용)
- `user.jpg`: 기본 프로필 이미지

## 이번 버전에 구현한 것
- 기존 1대1 시간 협상(5분 단위), READY, 서버 승패 계산, 기권, GPS 기본 필터 및 점수 연출 유지
- 로그인 이후 최초 닉네임 지정, 프로필 사진 업로드/촬영/기본값, 서버 저장
- 닉네임 서버 검증(금지어 목록 포함), 아이디/비밀번호 변경, 계정 삭제
- 로그인/로비/인게임/결과/전적/프로필/설정 화면, 하단 탐색 메뉴
- 다크/화이트 테마, 글자 크기 설정, 서버 주소 자동 로컬 저장
- 첫 계정 로그인 시 탭으로 넘기는 규칙 안내
- 경로 지도: Leaflet + OpenStreetMap 타일(인터넷 필요), GPS 경로와 1km 구간 기록
- 온라인 경로 공유는 READY 단계에서 **직접 체크한 경우에만** 서버에 전송/보관/상대에게 공개. 좌표는 소수점 넷째 자리로 축약, 최대 600점
- 연습 경로는 기기 로컬에 저장; 별도 체크한 경우에만 서버에도 전송
- 온라인 경기 전적 서버 저장, 로그인한 계정의 서버 전적 열람, 상대 경로가 공유된 경우 함께 지도 표시
- 로딩 화면에서 회전 애니메이션 제거, RA 로고 표시

## 아직 실제 운영 연동이 필요한 기능
**카카오/Google 소셜 로그인은 실제 OAuth로 연결되어 있지 않습니다.** 버튼은 준비 상태 안내만 표시합니다. 카카오 개발자 앱, Google Cloud OAuth 클라이언트, 승인된 리디렉션 URL, HTTPS 인증 백엔드 설정이 필요합니다. 테스트는 기존 아이디/비밀번호 로그인을 사용하세요. 소셜 로그인이 된다고 발표하면 안 됩니다.

지도는 Leaflet과 OpenStreetMap 공개 타일 서버를 사용합니다. 지도 서비스 업체의 API 키를 발급받은 형태는 아닙니다. 인터넷 연결 및 서비스 이용 정책 준수가 필요하고, 대규모 배포 시 정식 타일 제공자 계약을 고려하세요.

**보안 안내:** 기존 WebSocket `ws://`과 프로토타입 인증/계정 변경 기능은 공용 인터넷 배포 수준의 보안이 아닙니다. 학교 내 승인된 테스트 환경에서만 사용하고, 실제 비밀번호/민감한 경로를 입력하지 마세요. 공개 서비스는 HTTPS/WSS, 로그인 세션 강화, 재인증, 요청 제한, 위치 데이터 보관/삭제 정책이 추가로 필요합니다.

GPS는 HTTPS 또는 localhost와 브라우저 위치 권한이 필요합니다. 학교 컴퓨터의 Windows 위치 기능이 차단되어 있으면 실제 이동 거리 측정은 작동하지 않을 수 있습니다. 안티치트는 기초 이상치 검사이며 GPS 조작을 완벽히 차단하지 않습니다.

## 점수 규칙
`S = round(100 × 거리(km) × (0.7 + 0.3 × min(평균속도(km/h)/12, 1)))`

## 개발 참고
서버와 브라우저는 **모두 이번 버전으로 교체**해야 합니다. 이전 버전의 서버와 새 클라이언트를 섞으면 프로필/전적 메시지가 작동하지 않습니다. 지도 라이브러리를 불러오지 못하면 지도는 표시되지 않지만 기본 경기 기능은 동작하도록 구성했습니다.
